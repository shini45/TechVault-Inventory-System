# TechVault Inventory System

## Overview

TechVault Inventory System is a Windows Forms inventory management application integrated with an ASP.NET Core Web API. It allows users to manage technology inventory items through CRUD operations.

## Features

- Add inventory items
- Update inventory records
- Delete inventory items
- Search inventory items
- View inventory list
- Low stock warning feature

## Technologies Used

- C#
- .NET 8
- ASP.NET Core Web API
- Windows Forms
- Visual Studio
- GitHub

## API Functions

- GET - Retrieve all items
- GET by ID - Retrieve a specific item
- POST - Add a new item
- PUT - Update an existing item
- DELETE - Remove an item

## Application Description

TechVault Inventory System helps users organize and monitor technology assets such as laptops, keyboards, monitors, and other computer-related equipment through a simple and user-friendly interface.
